<h1 align="left">Project Description</h1>

<p align="left">Bus Management System is a Java-based application designed to facilitate the management of bus routes, ticket purchases, delay notifications, and payment processing. The system provides an interface for passengers, bus drivers, and dispatchers to interact with the system effectively.</p>

<h2 align="left">Features</h2>

<p align="left"> <b>Ticket Purchase System</b>: Users can purchase bus tickets by selecting route, date, time, and ticket type.
  
<b>Payment Processing</b>: Supports BLIK and card payment methods.

<b>Delay and Impediment Reporting</b>: Bus drivers can report route impediments and delays.

<b>Notification System</b>: Passengers can receive notifications about delays and route changes.

<b>User Roles</b>: Includes passengers, bus drivers, and dispatchers, each with specific functionalities.
